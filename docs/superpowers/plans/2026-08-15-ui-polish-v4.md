# Nexora UI Polish V4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the requested V4 UI refinements while preserving the stable Angular/backend integration.

**Architecture:** Reuse the current standalone Angular components and global design system. Extend existing reusable pagination and modal/lookup components instead of introducing new libraries or alternate flows.

**Tech Stack:** Angular 21.2, TypeScript 5.9, Bootstrap 5.3, RxJS 7.8.

## Global Constraints
- No backend endpoint or payload changes.
- No JWT; keep credentialed Spring Security session flow.
- Keep modal keyboard functionality but remove visible instructions.
- Page size 5 for tables/history/catalog master data and lookup results.
- Page size 8 for client product cards.
- Do not add UI dependencies.
